# 🎮 Jogo de Adivinhação em Python | Number Guessing Game

## 🇧🇷 Português

### Sobre o projeto
Este projeto consiste em um jogo de adivinhação desenvolvido em Python, no qual o computador escolhe aleatoriamente um número e o usuário precisa descobrir qual é.

### 🎯 Objetivo
Praticar lógica de programação e aplicar conceitos fundamentais da linguagem Python.

### ⚙️ Funcionalidades
- Geração de números aleatórios.
- Limite de 3 tentativas.
- Validação das entradas do usuário.
- Mensagens indicando se o número secreto é maior ou menor.
- Tratamento de entradas inválidas.

### 🛠️ Tecnologias utilizadas
- Python 3
- Módulo Random

### ▶️ Como executar
1. Instale o Python 3.
2. Clone este repositório.
3. Abra a pasta do projeto no terminal.
4. Execute:

```bash
python jogo_adivinhacao.py
```

### 📚 Conceitos praticados
- Variáveis e tipos de dados.
- Estruturas condicionais.
- Laços de repetição (`for` e `while`).
- Funções.
- Tratamento de exceções (`try` e `except`).
- Validação de dados.

### About the project
This project is a number guessing game developed in Python. The computer randomly selects a number, and the user must guess it.

### 🎯 Objective
Practice programming logic and apply fundamental Python concepts.

### ⚙️ Features
- Random number generation.
- Limit of 3 attempts.
- User input validation.
- Feedback indicating whether the secret number is higher or lower.
- Invalid input handling.

### 🛠️ Technologies
- Python 3
- Random module

### ▶️ How to run
1. Install Python 3.
2. Clone this repository.
3. Open the project folder in the terminal.
4. Run:

```bash
python jogo_adivinhacao.py
```

- Conditional statements.
